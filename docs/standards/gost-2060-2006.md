# ГОСТ 2060-2006 — диапазон массы по размеру

Источник: предоставленная пользователем страница «4 Сортамент», п.4.1, таблица 1 (2026-10-08). Область ГОСТ сверена с Росстандартом: https://protect.gost.ru/gost/details/bb7bc9c0-f59c-46cb-9c3d-7591ace51482

Подтверждены численные отклонения размеров тянутых круглых, квадратных и шестигранных латунных прутков до 50 мм, включительные верхние границы. Для квадратных и шестигранных размер — расстояние между параллельными гранями. Пустые клетки не интерполируются. Таблица не распространяется на прессованные прутки.

Расчётное следствие (не отдельный норматив массы): при постоянных длине и плотности m_min/m_nom=((d-delta)/d)^2, m_max/m_nom=((d+delta)/d)^2. Это только влияние размера сечения; отклонения длины, плотности, формы, состояния поставки не суммируются. Номинальная масса не корректируется средним процентом. Пример d=20 мм, delta=0.30 мм: -2.9775%/+3.0225%.

Граница реализации: численные данные только из полученной таблицы; остальные размеры и прессованные изделия рассчитываются по номинальному сечению без неподтверждённого диапазона. Отдельное ограничение ЛС63-3: только круглые 3–20 мм должно проверяться при добавлении этой марки (сейчас в каталоге отсутствует).

Дополнение: пользователь предоставил таблицу 2 прессованных прутков до 180 мм. Перенесены нормальная и повышенная точность для круглого, квадратного и шестигранного сечений. Знак «—» прямо означает, что пруток не изготовляют; в этих ячейках расчёт блокируется с объяснением. Диапазоны тянутых прутков свыше 50 мм пока не подтверждены.
