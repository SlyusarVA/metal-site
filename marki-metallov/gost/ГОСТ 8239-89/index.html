ГОСТ 8239-89

Двутавры стальные горячекатаные. Сортамент.

Область применения

Распространяется на горячекатаные двутавровые балки (I-профиль) номеров 10–60. Применяется в строительстве для перекрытий, колонн, эстакад, мостов.

Ключевые параметры

  • Номера профилей: 10, 12, 14, 16, 18, 20, 22, 24, 27, 30, 33, 36, 40, 45, 50, 55, 60
  • Номер ≈ высота профиля в см
  • Длина: 4–13 м мерная
  • Погонная масса: от 9.46 кг/м (№10) до 154.4 кг/м (№60)

Допуски

  • Отклонение по высоте H: ±2 мм
  • Отклонение по ширине полки B: ±3 мм
  • Отклонение по массе: ±3% на партию
  • Кривизна: не более 0.2% длины

Важно учитывать

  • Момент инерции резко возрастает с номером — выбирать с запасом по прогибу
  • Для сварных конструкций проверять свариваемость марки стали

Маркировка

Клеймение на полке: номер профиля, марка стали, номер плавки.
